# Telegram Crypto Trading Bot

Professional Telegram bot for crypto price tracking, alerts, and portfolio management.

## Features

- 📊 **Real-time Price Tracking** - Live crypto prices from multiple exchanges
- 🔔 **Custom Price Alerts** - Get notified when your target price is hit
- 💼 **Portfolio Management** - Track your holdings with P&L calculations
- 📈 **Multi-Exchange Support** - Binance, Coinbase, Kraken integration
- ⚡ **Fast & Reliable** - Built with python-telegram-bot async framework

## Tech Stack

- Python 3.10+
- python-telegram-bot (async)
- CoinGecko/Binance API
- SQLite for user data persistence

## Setup

```bash
pip install python-telegram-bot requests
export BOT_TOKEN="your_telegram_bot_token"
python bot.py
```

## Commands

- `/start` - Initialize bot
- `/price BTC` - Get current Bitcoin price
- `/alert BTC 50000` - Set alert when BTC hits $50k
- `/portfolio` - View your portfolio with P&L
- `/add BTC 0.5 45000` - Add position to portfolio
